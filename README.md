# Cloud-Based Vehicle Tracking System - Flask

Modules: Authentication, vehicle registration, live GPS tracking, geo-fence, ML anomaly detection, dashboard, reports, alerts.

## Run locally
```bash
python -m venv venv
source venv/bin/activate   # Windows: venv\Scripts\activate
pip install -r requirements.txt
cp .env.example .env
python run.py
```
Default login: admin@example.com / admin123
